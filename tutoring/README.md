# Tutoring track

The modules are published one at a time.
This repository currently holds the first two.

| | module | h | notebook |
|---|---|---|---|
| **M1** | Continuum mechanics | 2.5 | `M1_continuum` |
| **M2** | Constitutive laws, the tensile test | 3 | `M2_constitutive` |

The notebooks need no install. They are plain Python (numpy, matplotlib, sympy, scipy):
no bootstrap cell, nothing to set up. They run on a bare Colab runtime or on any local
Python. Each module folder also holds a `figures/` with the script that draws its
diagrams, so every picture in a notebook has a producer you can read.
